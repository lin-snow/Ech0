若你刚听说 Ech0，建议先读 [产品概览](/zh/docs/guide/overview)，再按本页顺序操作。下面假设你有一台能装 Docker 的 Linux 服务器或本机，目标是在 **10 分钟内** 打开网页并完成首次登录。

---

## 你会得到什么

完成本节后，你将拥有：

- 一个在浏览器里可访问的 Ech0 实例（默认端口 **6277**）
- 一个 **Owner（首个注册）** 账号，可管理站点与发帖权限
- 对「数据存在哪、如何备份」有基本概念

若你更关心**概念**而不是命令，可直接跳到 [名词与界面](#名词与界面)。

---

## 部署前：你需要准备什么

| 项目         | 说明                                                                                                                          |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| 一台机器     | 云服务器、NAS、树莓派或本机均可；需能装 **Docker**（推荐）或能运行官方二进制。                                                |
| 网络         | 本机试用：访问 `http://127.0.0.1:6277` 即可。公网访问：安全组/防火墙放行 **6277**（或你映射的端口）。                         |
| 域名（可选） | 不绑定域名也能用 IP 访问；若要用 HTTPS，需在反代（Nginx、Caddy 等）里配置证书，详见 [安装部署](/zh/docs/start/installation)。 |
| 签名密钥     | 无需准备：首次启动时服务会生成 JWT 密钥并存入数据库，重启与升级后会话仍然有效。                                              |

**不需要**提前会写 Go 或前端；自托管用户按文档跑容器即可。

---

## 第一步：一条命令启动（Docker）

在终端执行（与 [安装部署](/zh/docs/start/installation) 一致）：

```bash
docker run -d \
  --name ech0 \
  -p 6277:6277 \
  -v /opt/ech0/data:/app/data \
  sn0wl1n/ech0:latest
```

- `-v` 把数据存到宿主机 `/opt/ech0/data`，重装容器也不丢库；路径可按需修改。
- 若端口被占用，把左侧 `6277` 改成例如 `8080:6277`，浏览器则用新端口访问。
- 不需要填任何密钥：首次启动会自行生成签名密钥并存入数据库。`JWT_SECRET` 已不再读取——旧 compose 文件里的这一项会被忽略并在启动日志里告警，删掉即可。

**打不开的常见原因**：防火墙未放行、Docker 未启动、IP 填错（云服务器要用**公网 IP** 或绑定的域名）。

---

## 第二步：浏览器里完成初始化

1. 访问 `http://<你的 IP 或域名>:6277`。
2. 按向导 **注册第一个账号**。该账号会自动成为 **Owner**（最高权限）。
3. 进入后台或设置页，完成站点名称、服务地址等基础设置；签名密钥无需关心，首次启动时已自动生成并落库。

当前版本下，**发帖权限通常默认只给高权限账号**；普通注册用户可能只能浏览，需由管理员在设置里授权。若你「登录了但发不了帖」，先确认是否用 Owner 登录，或查 [常见问题](/zh/docs/start/faq)。

---

## 第三步：建议你马上做的几件事

1. **知道如何轮换签名密钥**（仅在确实需要时）：执行 `sqlite3 data/ech0.db "DELETE FROM key_values WHERE key='jwt_secret';"` 删掉密钥行后重启，已签发 token 全部失效，所有用户需重新登录。
2. **备份数据目录**：至少复制一份 `/opt/ech0/data`（或你的挂载路径）到别处。详见 [数据管理](/zh/docs/guide/datacontrol)。
3. **填写「服务地址」**（若用 Connect / 头像显示）：在 **系统设置 → 服务地址** 填本站完整 URL（含 `http://` 或 `https://`），与浏览器地址栏一致。
4. **规划 HTTPS**：公网站点建议用反代终止 TLS；仅内网可暂时 HTTP。

## 名词与界面

| 名词               | 含义                                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------------------------- |
| **Echo**           | 一条时间线动态（类似一条微博），可含 Markdown、图片、链接卡片等。                                       |
| **实例**           | 你部署的这一套 Ech0 服务；多实例之间可用 Connect / Hub 互联，见 [互联聚合](/zh/docs/guide/federation)。 |
| **Owner / 管理员** | 首个注册账号为 Owner；可在设置里管理用户与部分全站选项。                                                |
