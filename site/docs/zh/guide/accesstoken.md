---
title: 访问令牌
description: 给脚本、命令行和 AI 客户端使用的长期凭证
---

访问令牌是一串放在请求头里的密码，让脚本、命令行工具或 AI 客户端以你的身份调用 Ech0，而不必保存登录密码。

在 **系统设置 → 访问令牌** 创建；**只有管理员**可以创建和删除。

---

## 什么时候需要

| 你要做的事                        | 怎么办                                                                                        |
| --------------------------------- | --------------------------------------------------------------------------------------------- |
| 用 `ech0` 命令行                  | 登录时自动生成，不用手动建，见 [命令行（CLI）](/zh/docs/guide/cli)                            |
| 让脚本 / n8n 调 API               | 建一枚令牌，选 **公开客户端**                                                                 |
| 从外部系统发评论                  | 建令牌，受众选 **系统集成**，勾选 `comment:write`                                             |
| 连接 Cursor / Claude 等 AI 客户端 | 优先浏览器授权；不支持时建令牌，受众选 **MCP（AI Agent）**，见 [MCP 接入](/zh/docs/guide/mcp) |

---

## 创建

1. 管理员打开 **系统设置 → 访问令牌**。
2. 填写名称、有效期、受众（给谁用）和权限。
3. 创建后立刻复制整串令牌，**它只会显示一次**。

随时可以在列表里删除令牌，删除即吊销，无法找回。

---

## 使用

在请求头里带上：

```http
Authorization: Bearer <令牌>
```

具体接口路径与字段以你实例上的 **`/swagger/index.html`** 为准；不同版本可能略有差异。

---

## 受众怎么选

| 界面名称            | 内部值          | 用在哪                                            |
| ------------------- | --------------- | ------------------------------------------------- |
| **公开客户端**      | `public-client` | 浏览器外的一般 API 调用、自建小工具               |
| **命令行**          | `cli`           | `ech0` CLI 与脚本                                 |
| **系统集成**        | `integration`   | 集成评论：`POST /api/comments/integration`        |
| **MCP（AI Agent）** | `mcp-remote`    | 只用于连接 `/mcp`；MCP 浏览器授权签发的也是这一类 |

受众用错会被拒绝。例如用「公开客户端」令牌调 `/mcp` 会返回 403。

---

## 权限怎么选

按最小权限勾选。面板里的分组与下表一致：

| 分组    | 可选权限                                                                                    | 说明                                  |
| ------- | ------------------------------------------------------------------------------------------- | ------------------------------------- |
| 动态    | `echo:read` / `echo:write` / `echo:delete` / `echo:private`                                 | 读公开 / 发布编辑 / 删除 / 额外读私密 |
| 评论    | `comment:read` / `comment:write` / `comment:review` / `comment:delete` / `comment:settings` | 读 / 发 / 审核 / 删除 / 评论设置      |
| 文件    | `file:read` / `file:write` / `file:delete`                                                  | 读 / 上传与编辑 / 删除                |
| 互联    | `connect:read` / `connect:write` / `connect:delete`                                         | 读 / 添加 / 删除                      |
| 资料    | `profile:read` / `profile:write`                                                            | 读 / 修改个人资料                     |
| 站点    | `admin:site`                                                                                | 品牌、CORS、系统设置                  |
| 存储    | `admin:storage`                                                                             | S3 凭据与连接测试                     |
| 登录    | `admin:auth`                                                                                | OAuth2 / Passkey 策略                 |
| Webhook | `admin:webhook`                                                                             | Webhook 管理                          |
| AI      | `admin:agent`                                                                               | Agent / Embedding / Copilot           |
| 数据    | `admin:data`                                                                                | 迁移、导入导出、快照计划              |
| 运维    | `admin:ops`                                                                                 | 日志、更新检查、访问统计              |
| 用户    | `admin:user`                                                                                | 用户管理                              |
| MCP     | `mcp:read`                                                                                  | 只读 MCP 能力清单，不含工具调用       |

两条容易忽略的规则：

- **写不含删**：`write` 只覆盖发布与编辑，删除要单独勾 `*:delete`。
- 账号安全（Passkey、OAuth 绑定）、访问令牌管理和设备批准只接受浏览器登录，令牌调不了。

---

## 常见组合

| 想做什么       | 勾选                                                       |
| -------------- | ---------------------------------------------------------- |
| 只读拉取时间线 | `echo:read`                                                |
| 脚本发帖       | `echo:read`、`echo:write`                                  |
| 集成评论       | `comment:write`（受众选「系统集成」）                      |
| MCP 日常读写   | `echo:read`、`echo:write`、`comment:read`、`comment:write` |
| 管理 Webhook   | `admin:webhook`                                            |

---

## 有效期

| 选项      | 适合                     |
| --------- | ------------------------ |
| 约 8 小时 | 临时脚本、一次性任务     |
| 约 1 个月 | 个人长期自动化           |
| 长期有效  | 高风险，仅在可控环境使用 |

过期即失效。怀疑泄露时，立刻删除并新建一枚。

---

## 安全建议

- 把令牌当密码：不要写进公开仓库、不要截图外传；CI 用环境变量或密钥库。
- 能用短有效期就不用长期；能只读就不给写。
- `admin:*` 的令牌权限很大，只给完全信任的环境。
