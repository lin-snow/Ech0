为什么不是 Slidev / Marp

仓库里已经有四个同一体裁的产物

  • 成本：框架要一份 pnpm workspace、一个 lockfile、一条 CI 和版本跟随；换来的只是 Markdown 写稿。
  • 交付：会议要 PDF。@page + @media print 就是导出器，一行命令不用写。
  • 真相：真需要代码高亮、复杂构图时，最后还是落回 HTML —— 中间那层只会挡路。
要点：不要为一个季度讲一次的产物引入第二个前端工具链。
