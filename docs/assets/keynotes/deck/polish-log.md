> 每一轮都靠截图逐页看，只改最伤的三处。改完复看，不复看不算改完。

## 第 1 轮 — 首次整册截图（10 页）

看到的问题：

1. 第 04 页产品截图压在说明文字上，正文被 macOS 窗口标题栏盖住。
2. 第 05、06、07、08 页标题与正文之间空了 250–300px，像内容掉到页面底部。
3. 第 09 页四个数字是灰色，不是白色，最大号数字反而最弱。

改动：

- 第 04 页：截图从 `bottom:-368px` 改为 `top:396px` 居中，说明文字收到一行（`26px`），字号从三行降到一行。
- 内容页统一改成 `flex:1` + 固定上边距（48–64px）+ `align-content:start|space-between`，删掉 `margin-top:auto`。
- 第 09 页：`.stat .num` 显式 `color:var(--ink)`——`deck.css` 里 `:where(.slide) p` 的 `--ink-2` 会顺着层叠赢过裸 `p`。

## 第 4 轮 — 14 页重排后的收口

按外部的 14 页框架重排后（四段：The Story / The Product / The Engineering / The Impact），逐页校对了截图的排版缺陷：

- 第 06 页：终端原本 `flex:1` 撑满整页、内容居中，看起来像「占位符」；改成整幅卡片 + 下方四格数据，命令 36px、卡片用 `--line-strong` 描边，页面才有重心。
- 第 09 / 10 / 11 页：两个（或三个）框架的四条记录各自成流，行起点不齐。改用 CSS `subgrid`——`.beats` 一条 5 行网格（标签 + 4 条），每个 `.beat` 和它的 `dl` 都 `grid-template-rows: subgrid`，跨列的行起点因此严格对齐。
- 第 13 页：四列负责人说明下方留了半个页面的空洞。改成列内 `flex` + `.ev{margin-top:auto}`，把证据行沉到列底，空洞变成上下两段结构。
- 第 03 页 `.neg` 清单原用 `--ink-3`（3.5:1）读起来像禁用态，退到 `--ink-2`。
- 行内 `code` 原来吃掉 `--ink`（纯白），一屏十几个标识符比正文更响；新增 `--code:#cfcac4`（≈11:1）压一档，`.layer.hi code` 仍走 `--accent-ink`。
- `.verdict`（各工程页的一句话结论）40px 会跟标题抢读，收到 36px / `max-width:1240px`。
- PDF：`--print-to-pdf` 得 14 页，MediaBox `[0 0 1200 675.12]`，无空白页。

## 第 5 轮 — 换字

用户反馈「字体不太好看」。原来的问题不是缺字体，是**只有一个声音**：标题、正文、标签全是黑体（PingFang SC）+ 等宽数字，层级只靠字号，投影上就显得平。

改成三声部（都写进 `style.css` 的 `--font-display`，不引外部字体文件，deck 仍然零依赖离线可用）：

- **大字**：`Songti SC`（回退 `Noto Serif SC` / `Source Han Serif SC` / `serif`），`font-weight: 900`（宋体 Black），`letter-spacing: 0`——宋体自带边距，负数会挤在一起。只给 `h1` / `h2` / `.h-lg` / `.vs-list` / `.creed` 用；**`.verdict` 留在黑体**，否则一页两个「标题声」。
- **正文**：PingFang SC（`--font-ui`），不动。
- **标签/数据**：等宽（`--font-mono`），不动。

顺带修的两处：

- 光晕从 `box-shadow: 0 0 260px 100px` 换成 `.orb::after` 的径向渐变层。大半径 box-shadow 在缩放画布上会露出发丝状矩形接缝（截图里在封面右上能看到硬边），渐变层没有这个问题。
- 第 10 页一句 dd 在 2 行处掉了一个孤字「时。」，改写成「…挂在一次 HTTP 请求里必然超时。」

- **标题语言换了**：英文标题用 `Helvetica Neue` 700（与 `og-cover.jpg` 上的品牌字同源），中文短句用宋体 900。旧版把中文当主标题、英文当标签，和 Ech0 自己的视觉资产是反的。
- **08 架构页**从「节点 + 连线」改成整幅五行分层（Clients / Application / Core / Data / Infrastructure），左右两端对齐——连线图在这个尺度上只剩噪点。
