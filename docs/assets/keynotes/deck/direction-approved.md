# 方向选定

> 记录这份 deck 为什么长这样。改动版式前先读这一页。

## 选定方向：D2 黑场（深黑 + 发光橙球 + 出血截图）

三个方向各自做过 2 页代表页（封面 + 产品页），留档在 [`../design-demos/`](../design-demos/)：

| 方向 | 定位 | 结论 |
|---|---|---|
| D1 白纸巨字 | 暖白底、176px 巨字、截图压住标题 | 技术页（架构、代码、表格）会因细线 + 小字显得空，且暖白底是 2026 年 AI 生成的默认外观之一 |
| **D2 黑场** | 近黑底、发光橙球、截图出血到画布外 | **采用**。技术内容在暗底是「蓝图」语汇；产品截图成为页面唯一最亮物，视线自动落上去 |
| D3 二分 | 左白右黑 / 左橙右黑 | 每页都被切成两块，架构图与代码切不进去；只借用它的整幅橙做第 03 页（愿景转折） |

## 证据

- 用户看过三方向对照图后：「看起来不错」。
- 用户随后问：「你觉得哪个最适合用于产品宣讲和技术讲解？」——由提案方定基线，不再摆选项。
- 佐证素材：`docs/assets/architecture/Ech0技术架构图.png` 是 11620×12438 竖构图、奶油底 + 薄荷绿块 + 蓝箭头，16:9 放不下也不合暗场语汇，因此第 06 页的架构图是**用 CSS 重画**的（边框 + 单色等宽标签），没有直接贴图。

## 工艺继承

- 品牌资产是 `web/public/og-cover.jpg`：暖白底、重黑巨字、右上角穿出画面的**发光橙球**。D2 就是把这颗球搬到黑场上当光源，橙色 `#ff4d00` 是唯一强调色。
- 版式语法（巨字压边、单色等宽标签、零装饰线、每页一个重块）来自 D2 样张，不是通用模板。

## 纪律

- 一页最多一条装饰线；真正的分隔只用留白与对齐。
- 每页必须有一个「重块」：满幅橙、发光球、出血截图、148px 数字，或橙色实心瓦片（第 05 页）。没有重块的页面会「素」，这是本项目的硬约束（用户原话：「不能太素，对比度要高。不要到处画横线」）。
- `--ink-3`（#6b6660，3.5:1）对比度不足 4.5:1，只做装饰点，不承载信息；次级文字一律 `--ink-2`（#9b968f，6.8:1）。
