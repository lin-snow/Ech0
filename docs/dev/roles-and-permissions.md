# 角色与权限

> **本文只描述当前已实现的行为。** 目标模型（账户状态 `ACTIVE` / `DISABLED`、账户永久删除的数据范围、三权限域）见 [user-permission-model-design.md](./user-permission-model-design.md)；两者冲突时，以设计文档为目标、以本文为现状。

Ech0 的账号只有两种角色，另有未登录访客。判定字段是 `users.is_admin`：

| 角色 | 判定 | 说明 |
|------|------|------|
| admin（管理员） | `is_admin = true` | 实例运营者，可以修改实例层面的任何配置 |
| member（成员） | `is_admin = false` | 正常账号，拥有自己的内容，但不碰实例配置 |
| 访客 | 无会话 | 只能读公开内容，评论走匿名流程 |

初始化创建的第一个账号是 admin（`UserService.InitOwner`），自助注册一律是 member，注册还受账号数上限约束（`authModel.MAX_USER_COUNT`，见 `internal/service/user/user.go`）。角色只表示"能不能动实例"，不表示"能不能写内容"——登录即可发布。

## 内容与数据

| 能力 | member | admin |
|------|--------|-------|
| 发布 echo | ✅ | ✅ |
| 编辑 / 删除自己的 echo | ✅ | ✅ |
| 编辑 / 删除他人的 echo | ❌ | ✅ |
| 查看公开 echo | ✅ | ✅ |
| 查看私密 echo（信息流与单条） | ✅ 所有登录用户共享，不按用户隔离 | ✅ 同左（匿名不可见） |
| 上传文件 / 记录外链文件 / 申请预签名 URL | ✅ | ✅ |
| 读取、修改、删除自己上传的文件 | ✅ | ✅ |
| 读取、修改、删除他人上传的文件 | ❌ | ✅ |
| 文件列表 / 目录树 / 按路径流式读取 | ❌ | ✅ |
| 给 echo 挂附件 | 文件须由本人或该 echo 作者上传 | 同左（历史无主文件放行） |
| 创建标签（显式接口，或写 echo 时按名字隐式新建） | ✅ | ✅ |
| 删除标签 | ❌ | ✅ |

## 评论

| 能力 | member | admin |
|------|--------|-------|
| 发表评论 | ✅ 自动通过，来源记为 system，昵称取用户名、不带邮箱 | ✅ 同左 |
| 待审核列表 / 单条评论详情 | ❌ | ✅ |
| 审核、置顶、删除、批量操作 | ❌ | ✅ |
| 评论系统设置、发送测试邮件 | ❌ | ✅ |

私密 echo 的评论：匿名不能读、不能写；任何登录用户可读可写（与私密 echo 本身同一可见性）。成员的评论不进入审核队列；评论通知邮件只发给主管理员（最早创建的 admin，`GetPrimaryAdmin`）。评论删除属于审核动作，成员不能删除自己发出的评论。

## 实例与运营

| 能力 | member | admin |
|------|--------|-------|
| 个人资料 / 语言 / 头像 | ✅ | ✅ |
| 实例设置（系统、S3、Webhook、Agent、Embedding、OAuth2、Passkey、快照计划） | ❌ | ✅ |
| 访问令牌增删改查 | ❌ | ✅ |
| 铸造带 `admin:*` scope 的访问令牌 | ❌ | ✅ |
| 用户列表 / 删除用户 / 切换 admin | ❌ | ✅ |
| 数据迁移（快照导入 / 导出） | ❌ | ✅ |
| 仪表盘与统计 | ❌ | ✅ |
| Connect 配置 | ❌ | ✅ |
| Copilot / Agent 对话 | ❌ | ✅ |
| OAuth 授权批准、设备码批准 | ❌ | ✅（另需会话令牌） |

用户管理上有两道兜底：不能删除或降级自己；系统至少保留一位 admin，否则返回 `permission_denied`（`LAST_ADMIN_REQUIRED`）。

## 访客

未登录只能读取公开 echo 和已通过审核的评论。评论必须填写昵称与邮箱，网址只接受 `http(s)`；`RequireApproval` 打开时评论进入待审核。验证码、频率限制、重复内容检查对访客生效。

## 边界与实现位置

- 私密内容的过滤在 repository 层按查看者作用域下推（`model.PrivateScope`）：匿名请求只返回公开 echo；任何登录用户（不分角色）在信息流与单条读取中都能看到全部私密 echo。私密不提供账号间隔离。
- 内容类写操作（echo / 文件 / 评论）判"作者或管理员"；实例类操作一律 admin。新增接口时按此归类，不要给 member 打开实例写权限。
- 角色与访问令牌 scope 是两条独立的轴，不可互相替代：
  - Huma 端点带 `admin:*` scope 时，`secured()` 自动追加 `middleware.RequireAdminSession`（会话令牌 + 角色位）；裸 gin 路由组（文件、迁移、Copilot）没有这层中间件，由 service 层的 `user.IsAdmin` 判定；
  - 访问令牌端点走 `authz` scope，其中 `admin:*` 只能由管理员铸造（`internal/access/service.go`），普通账号签发的令牌天然到不了管理面。
